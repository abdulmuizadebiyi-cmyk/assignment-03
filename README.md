# Student Assignment Tracker

## Project Description

The Student Assignment Tracker is a web application that helps
students organize assignments, manage deadlines and track progress.

## Features

- Add new assignments
- View assignments
- Edit assignment details
- Delete assignments
- Track due dates, priorities and completion status
- Responsive website design

## Technologies Used

- Node.js
- ExpressJS
- MongoDB Atlas
- Mongoose
- EJS
- CSS
- GitHub
- Render 

## Running the Project

1. Install dependencies using `npm install`.
2. Create a `.env` file.
3. Set the `MONGODB_URI` environment variable.
4. Run `npm start`.
5. Open `http://localhost:3000`.
